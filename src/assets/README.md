# Assets aprobados

Colocar aquí imágenes, iconos y fuentes aprobadas para la app. No copiar las fotografías de concepto como catálogo real.
Las fuentes Inter y Fraunces se empaquetan localmente desde @expo-google-fonts; no se descargan al abrir la app.
Los originales de marca se conservan en design/brand. Incorporar cada exportación al implementar su componente.

`welcome/` contiene las ilustraciones SVG del rediseño de bienvenida aportado como ZIP. La fotografía y el icono de Figma 459:196 se conservan como activos anteriores; la Tienda todavía usa la fotografía editorial.
`products/` contiene cuatro fotografías conceptuales procedentes de design/assets para el catálogo de muestra.
La fotografía de temporada de `459:197` reutiliza el mismo archivo `welcome/pantry.png`; las fotos de arroz superior y lenteja coinciden exactamente con los activos de ese nodo, sin duplicarlas.
`navigation/` contiene los cuatro SVG exportados del nodo `459:197` y un icono local de regreso para `687:48`. `store/search.svg` es un icono vectorial local para el campo de búsqueda.
La fotografía de menestras de `687:48` coincide con `products/lentils.png`, pero la pantalla móvil de acceso ya no la muestra por indicación del usuario. Se conserva el archivo porque lo utiliza la Tienda.
Pueden reemplazarse manteniendo los nombres de archivo; revisar el encuadre de cada pantalla después del cambio.


Los SVG de store/redesign proceden del ZIP de Inicio aportado por el usuario el 4 de octubre de 2026. Sus ilustraciones son editoriales: las fichas siguen mostrando la imagen o portada del catálogo actual.
