# Catálogo

La pasada 3 usa las rutas anidadas en `/inventario/catalogo` para listado, producto/presentación y precio/historial. `src/services/mock/operationsCatalog.ts` selecciona tres presentaciones del catálogo de muestra compartido; sus importes no son precios vigentes ni las filas publicaciones confirmadas. Los formularios son borradores locales con guardado deshabilitado. Véase `docs/mobile/screens/operations-pass-3.md`.
