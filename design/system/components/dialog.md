# Cogana Dialog

Figma component set: `285:17`  
Page: `36 · Dialog` (`285:2`)  
Documentation frame: `285:760`

## Purpose

Centered modal for information or a clear interface choice. The host screen validates any business action separately.

## Variants

- `Type=Informative`: message and dismiss control.
- `Type=Choice`: message, primary action, and return action.

The dialogs are 328 px wide. Every action is 44 px high.

## Accessibility and boundaries

- Keep focus within the dialog while open and return it to the trigger when closed.
- State consequences and errors in text.
- Do not use this component to cancel, pay, confirm checkout, or modify an order without a separately authorized operation.

## Validation

Validation confirmed two variants, nine editable text properties, 44 px controls, and no clipping or overlap.
