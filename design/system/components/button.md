# Cogana Button

Figma component set: 33:2

## Purpose

Mobile actions for the customer and owner experiences. Buttons follow Cogana's
functional-minimal visual language, with rounded shapes, clear hierarchy, and
touch targets suitable for React Native.

## Variants

- Size: Small, Medium, Large
- Style: Primary, Secondary, Ghost
- State: Default, Pressed, Disabled
- Total: 27 variants

## Dimensions

- Small: 44 px high
- Medium: 48 px high
- Large: 56 px high

## Properties

- Label: editable text
- Show icon: toggles the trailing arrow

## Usage

- Primary: the single dominant action in a screen or modal.
- Secondary: a supporting action with commercial emphasis.
- Ghost: low-emphasis actions and compact navigation.
- Disabled: only when the action is genuinely unavailable.

Hover is intentionally excluded because the initial product is a React Native
mobile application. Interaction states are Default, Pressed, and Disabled.
