# Cogana — sistema de logotipo v1

Maestros vectoriales refinados a partir del logo original. El PNG de referencia no fue modificado.

## Archivos

- `cogana-logo-primary.svg`: composición vertical para portada, bienvenida y piezas institucionales.
- `cogana-logo-horizontal.svg`: composición para encabezados, navegación y espacios de poca altura.
- `cogana-symbol.svg`: símbolo detallado a todo color.
- `cogana-app-icon.svg`: tratamiento del símbolo sobre fondo verde para icono de aplicación.
- `cogana-symbol-optical-small.svg`: dibujo simplificado para 32 px o menos.

## Paleta principal

- Verde Cogana: `#2F6946`
- Dorado Mercado: `#E8AA31`
- Crema Natural: `#F8F5EC`

## Wordmark

El wordmark se construyó con **Fraunces Black Italic** y fue convertido a contornos. Los SVG no requieren que la fuente esté instalada.

## Reglas de uso

- Usar el símbolo detallado desde 48 px en adelante.
- Usar `cogana-symbol-optical-small.svg` entre 24 y 32 px.
- No deformar, rotar ni cambiar las proporciones internas.
- Mantener fondos transparentes en los logotipos principal y horizontal.
- El icono de aplicación incluye su propio fondo verde y no debe colocarse dentro de otro contenedor de color.
