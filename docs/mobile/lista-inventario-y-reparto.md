# Datos para habilitar inventario real y reparto

Completar una fila por presentación y lote físico. Si un producto tiene dos lotes o vencimientos, usar filas separadas.

| Producto / marca | Presentación / peso neto | Paquetes sellados disponibles | Cantidad suelta y unidad (g, ml o unidades) | Código de lote | Vencimiento, si corresponde | Proveedor, si se conoce |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

Indicar quién repartirá: el dueño o una persona con cuenta propia. Para personal nuevo basta nombre y correo/celular de acceso; no incluir contraseñas ni códigos OTP. También confirmar cuántas personas repartirán simultáneamente y cuándo se abrirá la tienda.

Los precios existentes no se modificarán al cargar existencias salvo instrucción expresa. La carga se contrastará con el catálogo para confirmar las presentaciones y unidades antes de registrarla.
